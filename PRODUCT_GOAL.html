Product Goal · Current Desired State

검과 방패로 마법 생물을 공략하는 Polygon RPG

플레이어는 마법 없이 기본기, 거리, 방향, guard, roll과 공중 연계를 숙련하고, 살아 있는 마을에서 준비해 서로 다른 Field와 Dungeon을 탐험하고 Boss를 쓰러뜨리며 전투 선택지를 확장한다.

Product Intent

Target Player

버튼 수보다 타이밍과 위치 선정, 읽기 쉬운 반응과 짧고 깊은 연계를 선호하는 2D 액션 RPG 플레이어.

Desired Outcome

플레이어는 실패 원인을 화면에서 이해하고, 준비와 원정을 반복할수록 새로운 command와 장비 선택으로 자신만의 공략 흐름을 만든다.

Core Player Flow

  1. Prepare
    학원촌에서 장비와 다음 목적지를 확인한다.
  2. Explore
    Field의 갈림길, 조우와 환경 단서를 읽는다.
  3. Delve
    Dungeon의 checkpoint와 전투 관문을 통과한다.
  4. Confront
    Boss의 telegraph를 읽고 기본기로 공략한다.
  5. Reward
    장비, 재화와 command 확장을 획득한다.
  6. Return
    열린 shortcut으로 마을에 돌아와 다음 원정을 준비한다.

Product Requirements

Identifier는 현재 제품, Gap과 verification evidence를 연결하며 개발 순서나 과거 version을 뜻하지 않는다.

PG-COMBAT-CONTROL

기본기 중심의 전투를 직접 조작한다

  • 이동, jump, guard, 방향 roll과 Basic/Strong 두 공격 입력이 공통 command grammar를 이룬다.
  • 지상과 공중의 짧은 sequence, launcher, 명시된 cancel window와 finisher를 입력 타이밍과 위치로 연결한다.
  • Guard 가능한 공격과 roll로 통과해야 하는 공격을 구분하며, 무분별한 공격은 recovery와 counter 위험을 만든다.
  • Basic/Strong 공격, guard와 roll은 stamina를 소비하고, guard로 공격을 막으면 stamina가 크게 줄어 같은 action을 계속 난사할 수 없다.
  • Strong 공격은 느리고 읽을 수 있는 준비 동작 뒤 guard를 깨지만, 준비 중 상대의 공격에 맞으면 Player와 적 모두 취소된다.
  • 입력 buffer와 cancel은 관대하지만 whiff, 잘못된 방향과 늦은 대응의 결과는 일관된다.

PG-COMBAT-FEEDBACK

전투 결과와 원인을 즉시 읽는다

  • 적중, block, evade, punish, launch, landing과 무적은 색, 동작, hit-stop과 위치가 서로 다르게 보인다.
  • Impact는 실제 weapon과 hurt area가 접촉한 위치에 고정되고 knockback 뒤 다른 위치로 떠다니지 않는다.
  • 공중 combo 보호 규칙은 연계를 임의로 끊지 않으며, 다음 neutral의 retaliation 보호는 해당 캐릭터 silhouette에 붙어 읽힌다.
  • Polygon과 Retro 출력은 같은 판정과 같은 원인·결과를 전달한다.

PG-WORLD-JOURNEY

마을에서 출발하는 하나의 완전한 원정을 경험한다

  • 학원촌은 장비 선택, 이름과 역할이 읽히는 인물·시설, 상호작용과 다음 목적을 이해하는 실제 생활 공간으로 기능한다.
  • Field, Dungeon과 Boss 공간은 이름만 다른 전투 방이 아니라 지형, 이동 경로, 환경 이야기와 조우 역할이 구분된다.
  • 첫 원정은 준비, 이야기 사건, 이동, route 선택, checkpoint, Boss, 보상과 shortcut 귀환을 debug 조작 없이 끝까지 진행한다.
  • 이야기는 고정 설명문만 띄우지 않고 인물·대상과의 상호작용에서 이름이 붙은 말풍선 대화로 진행되며, 대화 중 같은 jump 입력은 다음 대사를 진행하고 jump를 발생시키지 않는다.
  • 현재 목표와 이야기 변화는 인물 반응, 환경 상태, HUD와 이용 가능한 길에 일관되게 반영된다.

PG-WORLD-SPACE

지역과 출입구가 실제 장소처럼 연결된다

  • Room은 이동 가능한 바닥, 경계, 전경·배경, landmark와 전투 공간이 한 장면으로 읽힌다.
  • Dungeon은 입구, 탐색·전투 구간, checkpoint와 Boss 진입 경계가 서로 다른 공간 역할과 위험으로 구분된다.
  • Portal은 공통 차원문이 아니라 문, 계단, 골목, 뿌리 arch, 석문과 결정 틈처럼 주변 환경의 일부로 보인다.
  • 출입구의 개구부는 플레이어와 비슷한 사람 크기이며 camera travel이 목적지 방향과 공간 깊이를 전달한다.
  • 낮밤, story와 local event 변화는 기존 공간의 의미를 바꾸되 필수 경로를 끊지 않는다.

PG-GROWTH-CHOICE

성장은 기존 전투 선택을 확장한다

  • 장비는 공격, 방어, 속도, 사거리, 경직, launch와 guard 성질 사이의 읽을 수 있는 trade-off를 제공한다.
  • 재화, 장비와 command 해금은 Field 탐색, Dungeon 공략과 Boss 보상에 연결되며 마을에서 다음 선택으로 이어진다.
  • 성장은 별도 cooldown 버튼을 늘리는 대신 같은 command의 성질, branch와 cancel route를 확장한다.
  • 획득한 성장, Boss 결과, 보상과 열린 shortcut은 같은 기기에서 다시 열어도 유지된다.

PG-CHARACTER-READABILITY

작은 화면에서도 캐릭터의 정체성과 동작을 읽는다

  • 인간형은 작은 머리, 가늘고 긴 몸통·팔다리의 stickman형 비율 위에 큰 장비 면을 얹는다.
  • 플레이어는 머리 방향과 머리카락, 교복형 천, 어깨 장비, 흉갑, 장갑, 부츠, 손, 검과 방패가 기본 배율에서 구분된다.
  • 대표 인간형 적은 색 분할, 장비와 자세가 플레이어와 즉시 구분된다.
  • Idle, 이동, guard, roll, 지상·공중 공격과 피격 pose에서 polygon이 겹치거나 silhouette가 무너지지 않는다.

PG-PLATFORM-ACCESS

Desktop과 mobile에서 같은 핵심 흐름을 수행한다

  • Keyboard와 touch control은 같은 gameplay intent와 command 결과를 만든다.
  • Mobile landscape와 desktop에서 HUD, 현재 목표, 캐릭터와 전투 공간이 서로 가리지 않으며 목표를 숨기지 않는다.
  • 메뉴와 화면 전환 control은 text 또는 accessible name으로 목적을 식별하고 keyboard로 사용할 수 있다.
  • Reduced-motion 환경에서도 판정 이해에 필요한 feedback은 유지된다.

PG-RECOVERY

진행 실패와 복구 결과가 명확하다

  • 저장 실패나 손상된 진행은 성공한 것처럼 보이지 않고 재시도 또는 초기화 영향을 설명한다.
  • Room 전환 중에는 입력이 도착 후 재생되지 않으며 Player, collision, entity와 목표가 함께 전환된다.
  • KO, encounter reset과 마을 귀환은 보상 중복이나 shortcut 역전을 만들지 않는다.

World and Story Surfaces

각 공간은 현재 목표와 플레이 선택을 보여 주는 제품 표면이다. 단순한 배경 교체나 debug selector로 대체하지 않는다.

Academy Village

훈련생의 출발점. 장비, 인물, 시설, 귀환 변화와 다음 원정의 동기를 보여 준다.

Field Route

우회와 전투, 환경 단서와 보상을 선택하며 Dungeon 입구까지 이동한다.

Dungeon

Field보다 폐쇄적이고 위험한 공간에서 checkpoint와 Boss 진입 조건을 확보한다.

Boss Arena

지역의 위협과 학습한 전투 규칙을 하나의 명확한 encounter로 시험한다.

Reward and Shortcut

승리 결과가 보상, 열린 길과 공간 변화로 나타나 귀환 부담을 줄인다.

Village Return

귀환한 Player가 성장 결과와 다음 이야기 목표를 확인하고 새 원정을 준비한다.

Product Constraints

  • 제품은 별도 설치나 계정 없이 current desktop/mobile browser에서 핵심 흐름을 실행한다.
  • Player는 마법을 직접 사용하지 않으며 검, 방패, 장비와 신체 동작으로 마법 생물을 공략한다.
  • Polygon 제작 효율과 Retro Pixel 가독성을 함께 유지하며 asset·character·story를 Reference에서 복제하지 않는다.
  • 자유 Z축 belt-scroll, cooldown skill 순환, 직접 stat point 분배와 대량 콘텐츠 선행은 현재 제품 정체성에 포함하지 않는다.

Product Experience References

레전드 오브 곡괭이

작은 화면에서도 강한 silhouette, 가늘고 과장된 인간형 비율, 기본기 중심의 횡스크롤 action과 마을 준비에서 원정·Boss로 이어지는 흐름을 원칙으로 참고한다.

케로로파이터

적은 기본 입력으로 시작해 방향, 위치, timing, guard, 회피, cancel과 공중 연계 숙련으로 보상이 커지는 command grammar와 즉시 읽히는 타격 feedback을 원칙으로 참고한다.

Reference의 character, 명칭, story, map, item, motion, sprite, sound, 원본 command열과 balance 수치는 복제하지 않는다.
