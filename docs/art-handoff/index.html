그래픽 제작 요청 안내

인물의 역할과 이야기의 인과를 먼저 읽고, 제작할 묶음의 원본 ID를 골라 요청합니다.

제품 기준은 Product Goal입니다. 이 문서는 확정된 제작 계약과 현재 작성된 자료를 구분합니다. 승인 reference가 형태·구도·주요 pose의 기준이며 현재 코드가 그 승인을 대신하지 않습니다. 등록됨 ≠ 디자인 승인·구현 완료. 미정·충돌 확인을 함께 읽으세요.

담당자에게 전달할 순서

  1. 공통 아트 기준와 Master SVG 제작 계약 — 실제 제작 reference와 원본
  2. 인물·NPC 역할표 또는 몹·Boss 역할표 — 같은 사람의 상태 변형과 별도 디자인 구분
  3. 전체 이야기 개요 → 담당 도입 / 지역 한 편 — 장소·등장인물·필요 그래픽
  4. 요청서 양식에 대상과 상태를 복사하고 미정 사항을 남깁니다.

목록의 수를 제작 건수로 해석하지 않기

현재 검토실은 597개 항목입니다. NPC 분류 113개에는 조립 묶음 26개와 몸/도구 조각이 함께 들어갑니다. 아래 인물표는 이를 13개 NPC 역할 묶음과 주인공 1개로 정리합니다. 갇힌 작업자 묶음은 한 명으로 확정한 것이 아닙니다.

5단계 reference 제작·승인 순서

Hero/Rival/Owner → Control Core/Retrieval Arm → Ancient Machine Awakening → Garage 0% → 실제 gameplay-scale prologue composite를 먼저 제작·승인합니다. 이 기준 장면을 승인한 뒤 enemy archetype → 폐광↔항구 → 나머지 지역으로 확장합니다. 계약 확정은 reference나 runtime 구현 완료의 승인이 아닙니다.
