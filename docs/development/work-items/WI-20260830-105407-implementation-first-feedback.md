# 구현 우선·실체 기반 피드백 workflow

## 팀장 원문

> 필요한 의도는 이미 말했으니 구현 전 확인 문서를 다시 승인받지 않는다. 먼저 구현하고 실제 코드 트리와 업무보고를 보여 주면 그 결과를 기준으로 피드백한다.

> 정말 개발 전에 물어야 할 내용은 긴 문서가 아니라 한 번에 하나의 짧은 인터뷰로 묻는다. 답은 Yes/No 또는 여러 선택지 중 하나로 결정 방향만 받는다.

## 결과

진행 중.

## 연결

- 실제 변경 코드 트리와 검증 결과는 완료 시 기록한다.
