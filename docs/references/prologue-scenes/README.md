# 도입 맵·플레이 진행 시안

Human이 동일 맵의 대화·적 처치 반복을 지적해, 기존 도입 이야기 안에서 공간과 진행 방식이 다른 3안을 제시한다. 모든 그림은 ImageGen으로 만든 구성 후보이며 맵 구현이나 기계 디자인의 승인본이 아니다.

- 1안: 상층 선별 데크 → 붕괴 후 하부 제어실 → 하층 귀환 통로
- 2안: 운반 레일 둑길 → 수거 게이트 → 흉곽 내부 → 바뀐 외곽 귀환길
- 3안: 거대한 폐병기 외곽의 상·하 접근로 → 흉곽 합류 → 각성으로 달라진 탈출

각 그림의 01~06은 `scripts/prologue-scene-candidates.mjs`의 장소·행동·변화·진행 조건 표와 대응한다. 생성된 위키 문서는 `docs/art-handoff/prologue-map-candidates.html`이다. 정확한 생성 프롬프트와 검수 보정은 [PROMPTS.md](./PROMPTS.md)에 보존한다.

Human 선택 전에는 한 안을 Product Goal의 확정 맵으로 만들거나 runtime에 적용하지 않는다. 귀환 시 핵은 한 개이고, 차고는 지역 부품이 설치되기 전 0% 상태다. 핵·회수팔·고대 병기의 세부 형태는 후속 자산 reference 검수와 구분한다.
